# H2 Dances (website)

Static site: 45 example dances (five per style) for the Unitree H2, rendered from the retargeted reference motions, and a
3D viewer (`viewer/`) for every dance. The full dataset is on Hugging Face: https://huggingface.co/datasets/Kyry10/h2-dances
No build step; serve the folder as static files. Same layout as G1 Dances and K1 Dances (https://kyry.me/k1-dances/).
Preserve the AIST citation requirement and use conditions (docs/).
