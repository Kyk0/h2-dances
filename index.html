Use it

Each dance is one NPZ file: a 60 fps reference trajectory for the 31-DoF H2, as a target for motion-imitation RL, for training a motion tracker, or for testing a whole-body controller.

These are motion references, not low-level robot commands. No tracking controller was run on them.

import numpy as np
from huggingface_hub import snapshot_download

path = snapshot_download("Kyry10/h2-dances", repo_type="dataset",
                         allow_patterns=["motions/*", "manifest.csv"])

with np.load(f"{path}/motions/gBR_sBM_cAll_d04_mBR0_ch01.npz") as m:
    qpos = m["qpos"]        # T x 38, 60 fps
root_xyz  = qpos[:, :3]     # metres, Z-up
root_wxyz = qpos[:, 3:7]    # unit quaternion
joints    = qpos[:, 7:]     # 31 joints, radians

Details & use conditions

1363 retargeted reference trajectories: every usable AIST++ clip that UMR retargeted. No tracking controller was run, so some clips may be hard or impossible to track. Some contain self-collision, foot sliding or a fast joint flip; per-clip metrics and a stricter subset (397 clips) are in the dataset. 39 of the 45 dances shown here pass that stricter screen; styles with fewer than five such clips are filled with the cleanest remaining ones. This is not hardware certification or a frame-by-frame manual review.

The videos show the retargeted target motion rendered in MuJoCo, not a controller simulation or a physical robot recording. No original AIST video, music or SMPL annotations are included.
